Files:
- index.html: Home page

- services.html: Hospitality services
- directory.html: Hotels & Restaurants directory
- gallery.html: Image gallery
- contact.html: Contact details and WhatsApp enquiry form

- script.js: Mobile navigation and WhatsApp form behaviour

HOW TO PREVIEW
1. Extract the ZIP file.
2. Open index.html in a modern browser.
3. For hosting, upload all HTML files, style.css, script.js and the complete assets folder to the website's public_html/root directory.
